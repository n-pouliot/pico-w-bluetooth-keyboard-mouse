PICO W BLUETOOTH KEYBOARD + MOUSE — FIRST SETUP
====================================================

You need only:
- the original Pico W board;
- a known USB data cable with a Micro-USB plug; and
- a charged BLE HID keyboard that supports entering a displayed passkey; and
- a charged BLE HID mouse.

The physically tested examples are the Logitech MX Mechanical keyboard and
Logitech M196 mouse.

Do this on the Windows PC first, not on the Xbox:

1. Keep the keyboard and mouse off. Unplug the Pico W.
2. Hold the Pico's white BOOTSEL button while plugging it into the PC.
3. Release BOOTSEL when the RPI-RP2 drive appears.
4. Copy pico-w-bluetooth-keyboard-mouse-v0.1.0-beta.1.uf2 to RPI-RP2.
5. The drive disappears and the Pico reboots. The LED should blink slowly.
6. Do NOT open Windows Bluetooth settings.
7. Put the keyboard into pairing mode. For an MX Mechanical, hold the chosen
   Easy-Switch key for about 3 seconds until its light blinks rapidly.
8. Watch the Pico LED. When it repeats THREE SHORT FLASHES AND A PAUSE,
   type 739241 on that keyboard and press Enter.
9. Wait for one short Pico flash every 2 seconds: keyboard ready.
10. Put only the separate BLE mouse into its documented pairing mode.
    Do not use the G502 LIGHTSPEED; it is not a BLE mouse.
11. Wait for the Pico LED to stay solid: keyboard and mouse ready.
12. Test letters, Shift/Ctrl, arrows, mouse movement/clicks/wheel on the PC.
13. Unplug the Pico for 10 seconds, reconnect normally (no BOOTSEL), and test
    that both devices reconnect without entering the code again.
14. Only after those PC checks pass, move the same Pico and cable to the Xbox.

The first-pairing window is 3 minutes. If it expires, unplug/reconnect the Pico
normally and retry only the missing device. A short Easy-Switch press does not
start pairing; hold the key until rapid blinking.

If Windows detection is unclear, double-click RUN-WINDOWS-DIAGNOSTIC.cmd in
this folder. It saves pico-w-bluetooth-keyboard-mouse-diagnostic-*.txt to the Desktop. Share that
small file along with the Pico LED pattern and exact mouse model.

Do not flash a MAINTENANCE file for first setup.

LOGITECH M196 RESULT (2026-09-02)
--------------------------------
The current v0.1.0-beta.1 file includes the M196 fix and physically passed
direct pairing, movement, and simultaneous basic use with the MX Mechanical on
Windows. Use that normal file in step 4.

The M196 pairing procedure is exactly: turn it on, then hold its bottom
on/off/pairing button for 3 seconds until its LED blinks. The Pico may briefly
show two green pulses while only the mouse is ready; solid green means both the
mouse and keyboard are connected.

XBOX RESULT (2026-09-02)
------------------------
The MX Mechanical and M196 both physically worked through the Pico in The Sims
4 on Xbox Series X. The mouse does not move around the Xbox Home dashboard;
that is expected because Xbox supports mouse input only in selected games and
apps. Test inside a title whose Store page says Console Keyboard & Mouse.
